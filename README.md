# AI vs John - AI-Powered Content Production System

AI vs John is a global TikTok series concept that uses satire to explore financial literacy through short dialogues between a rational AI advisor and a financially struggling character named John.

## Project Overview

- **Format:** 15-second satirical videos
- **Language:** English
- **Platforms:** TikTok and Instagram Reels
- **Target Audience:** Global audience, ages 18–40

## Characters

- **The AI:** A cold, rational, minimalist financial advisor.
- **John:** A financially struggling but hopeful character who constantly makes excuses.

## Key Components

- **AI Agent:** System prompt for managing and coordinating the content production workflow.
- **Character Development:** Character Bible and tone guidelines.
- **Script Production:** Structured episode format and scripts for Episodes 1–20.
- **Visual Production:** Prompts and guidelines for AI-generated visuals.
- **Voice Production:** Voice configuration guidelines.
- **Business Planning:** Monetization strategy, affiliate marketing, and sponsorship planning.
- **Performance Tracking:** Metrics and KPI tracking structure.

## Project Structure

The repository organizes production guidelines, scripts, AI prompts, business planning, and legal documentation into separate sections.

## Mission

Use sharp satire to expose financial delusion and encourage smarter financial decisions.

## Technologies & Tools

- AI Agents
- Prompt Engineering
- Leonardo AI
- ElevenLabs
- TikTok / Instagram Reels

## Project Status

The core project structure, character guidelines, and first 20 scripts have been prepared. Visual production, publishing, and monetization remain planned activities.
